# Favicon

Thay file `assets/icons/favicon/favicon.svg` bằng icon SVG của em, giữ nguyên tên file.

Đường dẫn trên web là `/assets/icons/favicon/favicon.svg`. Tất cả các trang đã gắn đường dẫn này.

Favicon người dùng đã thêm được giữ nguyên. Khi thay icon khác, nên dùng `viewBox` hình vuông để hiển thị đúng tỷ lệ.

Sau khi thay icon, nếu trình duyệt còn lưu favicon cũ, đổi `?v=1` thành `?v=2` tại thẻ `link rel="icon"` của các trang.
